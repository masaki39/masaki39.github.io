# Plugin Update Tracker

Obsidianはプラグインベースであるので、気づいたら相当な数のプラグインが入っている。アップデートは頻回に行われているが、能動的に見に行かないと気づかない事が多い。
Plugin Update Trackerはコミュニティプラグインのアップデート状況を自動監視し、新バージョンの通知とリリースノート確認ができるプラグインである。

> [!quote] [GitHub - swar8080/obsidian-plugin-update-tracker](https://github.com/swar8080/obsidian-plugin-update-tracker)

## 主な機能

ステータスバーにアップデート可能なプラグイン数を表示する。

![](https://filedn.com/lF97wFVWosQpHEoDAbvva0h/image_20250714092737.webp)

### リリースノート確認

各プラグインのリリースノートを表示し、アップデート内容を事前確認可能。
アップデートをスルーする選択肢もある。

![](https://filedn.com/lF97wFVWosQpHEoDAbvva0h/image_20250714092903.webp)

新機能追加、バグ修正、破壊的変更の有無を把握でき、安全なアップデートが行える。

## メリット

- アップデート通知の自動化
- リリースノートによる事前評価
- 個別プラグインの選択的アップデート
- ステータスバーでの控えめな通知
