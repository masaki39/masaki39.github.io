![|700x438](https://filedn.com/lF97wFVWosQpHEoDAbvva0h/Publish/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202025-05-27%2023.37.19.jpg)

↑デフォルトのサンドボックスに適応したスクリーンショット

やったことは以下の通り

- アクセントカラーの分配
- 見出しの下線、タイトルの中央配置、サイズ縮小
- プロパティの無駄な文字表記の非表示
- ノートの縁取り、余白
- サイドバー最下段のサイズ固定、ヘッダーの折りたたみ

# 使い方

1. Obsidianの設定画面
2. 外観
3. CSSスニペット
4. フォルダ内にこのファイルを入れて、有効にする
