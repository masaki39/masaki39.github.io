# Advanced Tables

![](https://filedn.com/lF97wFVWosQpHEoDAbvva0h/image_20260123223815.webp)

普段はオフにしている。マークダウンテーブルをcsv形式でコピーできるので、Obsidianに貼ったテーブルをExcelに貼り付ける時にだけオンにして使う。もっといい方法があるような気がする。

# Advanced URI

URIとは外部からObsidianの機能を利用するための仕組みである。[例えばこれをクリック](obsidian://daily)するとデイリーノートが開く。Advanced URIはその機能を拡張してコマンド実行とかもできる。

> [!quote] [[📘RaycastでObsidianのコマンドを実行する]]

このやり方で、ちょっとしたメモとかタスク追加とかをどこからでも行えるようにしている。コマンド実行くらいはそのうち公式機能で採用される気もしつつ、それまでは使おうと考えている。

# Another Quick Switcher

高機能＆高カスタマイズ性クイックスイッチャー。

![](https://filedn.com/lF97wFVWosQpHEoDAbvva0h/image_20260123224813.webp)

検索自体のカスタマイズに加え、検索から派生できるオプションが非常に多い。

![](https://filedn.com/lF97wFVWosQpHEoDAbvva0h/image_20260123225005.webp)

Grepによる全文検索にも対応している。検索系最強プラグイン。

# Auto Link Title

URLをノートにコピペするとそのページのタイトルを自動取得する。

```markdown
[Home](https://masaki39.github.io/)
```

テキスト選択中にペーストするとそのテキストにリンクが埋め込まれる。

```markdown
[砂の書庫](https://masaki39.github.io/)
```

自動取得しないペーストのオプションも当然用意されている。

# Better Word Count

通常のワードカウントに加え、オプションでセクションの単語数を自動表示することができる。抄録作成などの単語数上限があるものを作る時に使用する。普段は不要なオプションなのでオフしている。

# BRAT

![](https://filedn.com/lF97wFVWosQpHEoDAbvva0h/image_20260123225701.webp)

# Crystal

> [!quote] [GitHub - masaki39/obsidian-crystal: Obsidian plugin optimized for my personal use](https://github.com/masaki39/obsidian-crystal)

> [!quote] [[📘さようならTemplater]]

# Excalidraw

Obsidianの人気No.1プラグイン。ほとんど使用しないが、どうしてもテキストで表現できない時はあるので、簡単な図作成に使用する。

![](https://filedn.com/lF97wFVWosQpHEoDAbvva0h/image_20260124081954.webp)

専用ファイルが生成されるので汎用ファイルが売りのObsidianの思想と反するようだが、PNG出力にするとPNG画像作成プラグインとして汎用性を保つことができる。sceneを埋め込むオプションをオンにするとPNGからExcalidrawのファイルを復元することもできる。

# Outline Converter

バレットリストを繋がった文章にする自作プラグイン。最初に作ったプラグイン。

例えばこれが、

```markdown
- Project
	- Goals
		- Ship v1
	- Tasks
		- Write docs
		- Publish release
```

こうなる。

```markdown
## Project

### Goals
Ship v1

### Tasks
Write docs
Publish release
```

バレットリストで書くとよく構造化された文章になるので論文作成に向くのではという発想で作成した。リストで必要な要素を構造化して配置→文章化して調整みたいな流れがいいかなと思っている。インデントレベルに応じた一括Foldコマンドがついていてこれは汎用性が高い。

![](https://filedn.com/lF97wFVWosQpHEoDAbvva0h/image_20260124085919.webp)

Noteでも紹介いただいた。

> [!quote] [\[Obsidian Plugins\] Outline Converter｜Pouhon](https://note.com/pouhon01/n/n3bf75400f4b2)

# Simple Citations

Zotero連携用に作成した自作プラグイン。
私がObsidianを使用し始めたきっかけは下記記事である。

> [!quote] [An Academic Workflow: Zotero & Obsidian \| by Alexandra Phelan \| Medium](https://medium.com/@alexandraphelan/an-academic-workflow-zotero-obsidian-56bf918d51ab)

ZoteroからObsidianに論文情報を取り込んで管理して、そのままObsidian上で論文を書くこともできるという記事である。ただし、実際に運用してみるとテンプレ作成と手動操作の多さが面倒過ぎたので、プラグインを作ることになった。

![](https://github.com/masaki39/simple-citations/raw/main/assets/%E7%94%BB%E9%9D%A2%E5%8F%8E%E9%8C%B2%202025-03-25%2020.50.50.gif)

# Various Complements

リンクをどんどん追加できるObsidianの機能を底上げするプラグイン。リンク以外の補完もできる。

![](https://camo.githubusercontent.com/0e874b7d25db92ea69fa5f78077015b6718a9093143cc10736a37675cc4d6ab9/68747470733a2f2f746164617368692d61696b6177612e6769746875622e696f2f646f63732d6f6273696469616e2d766172696f75732d636f6d706c656d656e74732d706c7567696e2f7265736f75726365732f766172696f75732d636f6d706c656d656e74732e676966)

多機能であるが、私が使用しているのは

- Internal link complement: リンクを追加用
- Custom dictionary complement: 英単語やコールアウトなどの入力補助
- Fallback linkify: 文章を書いてから(空)リンクを追加できる

の3つである。

# おわりに

1年前と比較すると、コミュニティプラグインの数は大幅に減少し、その代わりに自作プラグインが増加した。大きな影響を与えたのはBasesの登場とAI Agentの発達により自作プラグインのハードルが下がったことだろう。
